# TakeHomeAI 💰

TakeHomeAI is a modern salary and tax calculator for India that helps users understand their **real take-home income**, compare **Old vs New tax regimes**, and view a complete **tax breakdown**.

## Features

* 🇮🇳 Indian tax slab calculation
* Compare **Old vs New tax regimes**
* Automatic **4% health & education cess**
* Salary breakdown
* **Monthly & Daily income**
* **LPA (Lakhs per annum) conversion**
* Modern UI built with React + Bootstrap + SCSS

## Tech Stack

* React (Vite)
* Bootstrap
* SCSS
* JavaScript

## Installation

Clone the repository:

```
git clone https://github.com/your-username/takehomeai.git
```

Install dependencies:

```
npm install
```

Run development server:

```
npm run dev
```
